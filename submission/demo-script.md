# 80-second demo

Record the real plugin in Hermes Desktop with system audio. Use the supplied Signal Garden example in a disposable or named demo composition, preserving existing work. Close unrelated panes and hide personal chat/session names. Set a comfortable output level before recording.

| Time | Show | Say |
| --- | --- | --- |
| 0–7 s | Sound Studio with the event library visible | “Hermes Sound Studio gives Hermes a sound of its own.” |
| 7–20 s | Select Confirm, move the XY pad, Audition once | “I can shape a sound locally, hear the result, and save it as an event assignment.” |
| 20–34 s | Enable desktop sounds; move to a real host button and toggle | “Now the target is Hermes Desktop. These are the patches playing on real interactions.” |
| 34–44 s | Change one assigned sound; repeat the host interaction | “Edits update the active assignment. The editor itself stays quiet.” |
| 44–61 s | Open Compose, play Signal Garden, change a velocity stalk | “The same synth becomes a compact loop instrument, with layers, a piano grid and note velocity.” |
| 61–72 s | Drag a loop handle, play, then Export WAV | “I can set the loop and export the actual rendered audio. JSON keeps it editable; TypeScript takes the sounds into another app.” |
| 72–80 s | Show status-bar Mute, then end on the full workspace | “It runs locally. Audio is explicit, and mute stays one click away.” |

Leave room for three clear audio moments: one audition, a short series of UI cues, and four seconds of the loop. Keep narration below the sounds. Use cuts for preparation/render waits; do not substitute a mock animation for a real result.

Do not spend the opening on implementation details, settings, the legacy workbench or a long feature list. Sound Draft can appear briefly in the written entry or an extended demo: it generates in the background, then presents Fine tune inside Studio. Capture a real generated patch, cut the wait transparently, and show a parameter change before acceptance. The core demo already shows a working instrument beyond prompting.
